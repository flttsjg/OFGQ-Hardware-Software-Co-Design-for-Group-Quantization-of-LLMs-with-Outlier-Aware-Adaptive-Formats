# Analysis

## R_cons

Run:

```bash
python analysis/compute_rcons.py --config configs/rcons_llama_example.yaml
```

The script computes sample-wise `D_intra`, `D_inter`, and `R_cons`, then reports layer-wise statistics and the percentage of samples with `R_cons > 1`.

## Local and cascaded MSE

Run:

```bash
python analysis/numerical_error_eval.py --config configs/numerical_error_llama_example.yaml
```

The local MSE independently quantizes and reconstructs the FP16 decoder input activation at each selected layer. The cascaded MSE compares the selected decoder-layer output of each quantized model with the FP16 reference output. The methods are E3M0, E2M1, E1M2, and OFGQ.

The default output files are:

```text
outputs/numerical_error/local_decoder_input_mse.csv
outputs/numerical_error/cascaded_decoder_output_mse.csv
outputs/numerical_error/combined_mse.csv
```

`numerical_error_eval.py` currently uses the LLaMA integration in this repository. The OFGQ metadata path must point to a calibration result generated by `scripts/calibrate.py` for the same model and sequence length.
